# Python File Organizer

This project automatically organizes files in a directory based on their file extensions.

## Features
- Sorts files into folders
- Supports documents, images, videos, spreadsheets, compressed files
- Automatically creates folders if not available

## Technologies Used
- Python
- OS module
- Shutil module

## How to Run
1. Run the Python script
2. Enter the directory path
3. Files will be automatically organized
